Product Description & Intended Use

The MSC Trust Inventory Management System (v2.0) is a web-based software application designed exclusively for the MSC Chellamuthu Trust & Research Foundation.

Intended Use

This software is intended to track, manage, and audit physical inventory items across various branches and specific blocks (e.g., rooms or wards). It allows staff to record inward and outward stock movements, perform transfers, and request item deletions, while allowing administrators to maintain global oversight.

Safety & Security Guidelines

To ensure data integrity and prevent unauthorized access, all users must adhere to the following guidelines:

🔒

Account Security

Never share your login credentials. Actions performed in the system are audited and tied to your user account. Do not leave the application open on unattended, unlocked computers.

Main Dashboard Elements

Upon successfully logging in, you will be presented with the Main Dashboard. This is your primary interface for all inventory operations.

Figure 3.1: The Main Dashboard Interface.

Key Interface Elements

  • Sidebar Navigation: Located on the left, allows access to Dashboard, Requests, Categories, Programs, and Admin Settings.
  • Summary Cards: At the top, displaying Total Items, Available Stock, and Low Stock Alerts.
  • Inventory Table: The central grid showing Item Names, Location (Branch/Block), Item Code, Serial No., and current Stock Levels.

Operating Instructions

Recording Stock Inward

When new supplies arrive at your branch, they must be recorded into the system to maintain accurate stock levels.

  1. Navigate to the Dashboard and click the Stock Inward button at the top right.
  2. In the modal window, use the Select an Item dropdown to choose the product.
  3. The system will automatically populate the Item Code and Serial No. if they exist.
  4. Enter the quantity received and any relevant reference notes.
  5. Click the save button to finalize the entry.

Figure 4.1: The Stock Inward recording interface.

Performing Stock Transfers

Items can be moved between Blocks within your Branch, or sent to an entirely different Branch.

  1. Click the Transfer Stock button.
  2. Select the origin branch and item.
  3. Select the destination branch and the specific destination block.
  4. Confirm the transfer. Note: Transfers to a different branch require Admin approval via the Requests panel.

Maintenance & Troubleshooting

Troubleshooting Common Issues

Problem: I cannot see inventory for other branches.

Solution: Standard Staff accounts are restricted to viewing only their assigned branch. If you require multi-branch access, please contact an Administrator to update your role permissions.

Problem: The "Select an Item" dropdown in the Stock Inward modal is empty.

Solution: Ensure that items have been created in the system and assigned to your branch first using the "Add Item" function.

System Maintenance

The system is maintained on centralized servers. No manual software updates or data backups are required by end-users. All data is automatically synchronized and backed up securely.
